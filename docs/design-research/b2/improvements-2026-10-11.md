# Axonis: UI/UX and motion improvements (11 Oct 2026)

> **Status (11 Oct 2026):** shipped:
> - real build progress and the honest overrun state: PR #7;
> - type filters, accent edges on focus and the cap of 8 neighbour labels: PR #8.
>
> Audit screenshots stay local in `.playwright-mcp/` and are not committed.

Builds on `implementation-spec.md`, `motion-map.md` (MM) and `../ux-patterns-mobbin-refero.md` (UXP). It doesn't repeat their picks. Where an earlier pick is still the best answer, it says so and adds only what's new.

Method: I opened https://axonis.app at 1440 px and 390 px. On the "AI tutoring" project (ready, 83 nodes, 68 edges, 14 clusters, 13 opportunities) I looked at Map, hover, select, Clusters, Opportunities, the Ask panel (opened only) and the mobile sheets. All requests were GET. Nothing was built, asked or uploaded. **I didn't open the Brief**, because it triggers LLM generation. I checked the code in `frontend/src` and `backend/` to see what the API actually reports. Sources: Mobbin and Refero MCP, the Motion docs MCP, the local Osmo vault mirror, and WebFetch sweeps of shadcn, AI Elements, prompt-kit, Magic UI, Aceternity, Motion Primitives, Kokonut (GitHub), Tremor, Bklit, anime.js and cli-spinners. ## 2. Top 12 improvements (ranked by value to the product ÷ effort)

The colour rule follows MM §0: magenta only for live, selected or spike, always paired with a second cue (a glyph, a bracket or a text tag). "RM" means `prefers-reduced-motion: reduce`, read through the existing `usePrefersReducedMotion` hook.

## 3. Rejected (and why)

- **Aceternity Multi Step Loader** (https://ui.aceternity.com/components/multi-step-loader): advances steps on a 2 s timer and loops by default. It's exactly the fake progress we're removing (A1).
- **prompt-kit Response Stream** (https://www.prompt-kit.com/docs/response-stream): simulates streaming on the client. Its own docs say not to use it for LLM output.
- **Mini-map** (cytoscape.js-navigator, https://github.com/cytoscape/cytoscape.js-navigator): current graphs have about 80 to 150 nodes and `[ FIT ]` already shows everything. A thumbnail would add chrome without adding information, and the repo has been quiet since March 2024. Revisit if graphs pass about 400 nodes.
- **Shimmer text** (AI Elements Shimmer, prompt-kit text-shimmer, Motion Primitives Text Shimmer): a gradient swept through text breaks the no-gradient rule. If a shimmer is ever needed, use a hard single-colour band stepped across (MM §13).
- **Motion Primitives Border Trail / Magic UI Border Beam / Shine Border**: a travelling glow around a frame. It's glow decoration that signals nothing real.
- **Magic UI Particles, Meteors, Retro Grid, Aurora; Aceternity Background Beams, Spotlight, Dotted Glow Background**: gradient or glow spectacle, extra colours, and no product meaning.
- **Random flicker loops** (Flickering Grid used as designed, Glyph Matrix with constant mutation): motion that doesn't correspond to anything happening. #2 keeps the grid but makes cells light only on real poll events.
- **Osmo Cursor Coordinates / custom cursors**: decorative, they fight Cytoscape's own pointer feedback, and they're hover-only.
- **Kokonut Hold Button**: there's no destructive action in the workspace that needs press-and-hold. The delete on Home is already a row action.
- **Bklit LiveLine with defaults** (pulse, badge, momentum colours): breaks the single-accent rule, and we have no throughput series to plot.
- **Aceternity Terminal / Magic UI Terminal for the real build**: scripted sequences. They're fine only for a marketing demo (as MM says), never for the live build.
- **Favicons in source chips** (prompt-kit Source pulls from Google's favicon service): a privacy leak and a CSP violation (`img-src`). Our sources are graph nodes anyway, so we use the type glyph.
